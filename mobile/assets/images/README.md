# Assets

Coloque aqui os seguintes arquivos de imagem:

- `icon.png` — Ícone do app (1024x1024)
- `adaptive-icon.png` — Ícone adaptativo Android (1024x1024)
- `splash-icon.png` — Imagem de splash screen (200x200)
- `favicon.png` — Favicon para web (32x32)
- `truck-placeholder.png` — Imagem placeholder para anúncios sem foto
